# 🐍 Snake Adventure - Interactive Food Game

A modern, beautiful Snake game built with HTML5 Canvas, CSS3, and JavaScript. Features multiple food types, power-ups, level progression, and responsive design.

## 🎮 Features

### Core Gameplay
- **Classic Snake Mechanics**: Move around the grid, eat food to grow longer
- **Multiple Food Types**: Different foods with unique effects
- **Level Progression**: Game gets faster as you level up
- **High Score System**: Persistent high score tracking
- **Collision Detection**: Wall and self-collision detection

### Food Types
- **🍎 Regular Food**: +1 point (70% spawn rate)
- **🍊 Bonus Food**: +3 points (20% spawn rate)
- **⚡ Speed Boost**: +1 point + temporary speed boost (10% spawn rate)

### Interactive Features
- **Pause/Resume**: Press SPACE to pause the game
- **Multiple Controls**: Arrow keys, WASD, or touch/swipe on mobile
- **Visual Effects**: Score animations, level-up celebrations, speed boost indicators
- **Responsive Design**: Works on desktop and mobile devices

### Modern UI/UX
- **Glassmorphism Design**: Beautiful blur effects and transparency
- **Smooth Animations**: Hover effects, transitions, and micro-interactions
- **Real-time Feedback**: Visual indicators for game state
- **Accessible Controls**: Clear button labels and keyboard shortcuts

## 🎯 How to Play

1. **Start the Game**: Click "Start Game" or press Enter
2. **Move the Snake**: Use arrow keys, WASD, or swipe on mobile
3. **Eat Food**: Collect different food types for points and effects
4. **Avoid Collisions**: Don't hit walls or your own tail
5. **Level Up**: Every 5 food items eaten increases your level
6. **Beat Your High Score**: Try to achieve the highest score possible

## 🎮 Controls

### Keyboard Controls
- **Arrow Keys** or **WASD**: Move snake
- **SPACE**: Pause/Resume game
- **ENTER**: Start game (when on start screen)

### Touch Controls (Mobile)
- **Swipe**: Swipe in any direction to move the snake
- **Tap Buttons**: Use on-screen buttons for game actions

## 🚀 How to Run

1. **Download Files**: Ensure all three files are in the same directory:
   - `snake-game.html`
   - `snake-game.css`
   - `snake-game.js`

2. **Open in Browser**: Simply open `snake-game.html` in any modern web browser

3. **No Dependencies**: The game runs entirely in the browser - no server or installation required

## 🔧 Customization

The game is easily customizable:
- **Grid Size**: Modify `gridSize` in the JavaScript
- **Game Speed**: Adjust `initialSpeed` for different difficulty
- **Food Types**: Add new food types in the `foodTypes` array
- **Visual Style**: Modify CSS variables for different themes
